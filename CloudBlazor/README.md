# CloudBlazor

Shared Blazor components and browser behaviors for all Blazor hosting models.

CloudBlazor is designed to work with:

- Static server-side rendering
- Interactive Server
- Interactive WebAssembly
- Interactive Auto
- Standalone Blazor WebAssembly
- .NET MAUI Blazor Hybrid

## Installation

```bash
dotnet add package AngryMonkey.CloudBlazor
